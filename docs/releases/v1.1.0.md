# Yode Desktop v1.1.0

Yode 1.1.0 是一次面向 Agent 能力、可靠性和 Desktop-first 产品方向的大版本升级。

## Agent Runtime

- 新增 YodeBench / `yode-evals` 评测数据模型与 Desktop 持久化接口。
- 新增 fail-closed `RunController` 状态机，覆盖 Discover → Plan → Execute → Verify → Replan → Deliver。
- 强化 Acceptance Criteria 与 Verification Gate：代码发生变更后，没有有效验证证据时不允许直接交付。
- 新增持久化 Repository Intelligence：文件、符号、依赖、关键词索引与增量更新。
- Agent DAG ready batch 改为真实并发执行。
- Browser 从 mock executor 升级为真实 Chromium CDP runtime。

## Model & Orchestration

- 新增 `ModelCapabilityRegistry` 和 `ModelRouter`。
- 支持 Explore / Plan / Implement / Verify / Summarize / Vision 分角色路由。
- ContextManager 统一使用模型能力注册表，不再维护独立的模型字符串判断表。
- 新增 Best-of-N、独立 Judge 与多轮 Debate runtime。
- 新增 Multi-repo DAG execution。

## Isolation & Execution

- 新增 OS Sandbox：Linux bubblewrap、macOS sandbox-exec，Strict 模式 fail-closed。
- Linux sandbox 增加真实 capability probe，避免“已安装但运行环境不允许”的假可用状态。
- 新增 Agent worktree 自动分配、提交、串行 merge 与冲突保留。
- 新增 Local / Docker / SSH / Cloud ExecutionBackend。
- Docker 默认关闭网络、只读 root filesystem，并显式挂载 workspace。

## Tooling & Delivery

- `tool_search` 升级为基于意图与能力的语义路由。
- 新增 GitHub Issue → Branch/Push → PR → CI checks 闭环。
- 新增 Postmortem + Learning journal 与重复失败经验聚合。
- 新增 Desktop Agent Intelligence 控制面，展示模型路由、Sandbox、ExecutionBackend 和 Learning 状态。

## Desktop-first

- 正式移除旧 root CLI/TUI package、安装器和 CLI 自更新器。
- README、PRODUCT、AGENTS、CLAUDE、CONTRIBUTING 统一为 Desktop GUI-first 产品方向。
- Desktop 更新检查改为真实 GitHub Release 路径，不再保留旧 CLI binary replacement 逻辑。

## Cross-platform Reliability

本版本集中修复了多项只会在干净 CI 或 Windows 环境出现的问题：

- Windows Hook 最小环境、UTF-16LE 输出与 LockFileEx 锁竞争语义。
- Windows structured hook JSON emitter 与 CRLF normalization。
- Windows TOML 路径测试序列化。
- Windows Desktop config backup fsync 句柄兼容。
- Windows Codex POSIX shell command 自动路由到 Git for Windows Bash。
- ExecutionBackend stdout/stderr pipe 捕获。
- LearningStore 跨进程锁和 Windows-safe 原子替换。
- `gpt-3.5` context capability 迁移兼容。
- Linux CI/Tauri 系统依赖与 workspace 依赖声明完整性。
